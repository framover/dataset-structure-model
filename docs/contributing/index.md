## Ways to contribute

- **Report issues** — open a GitHub issue for bugs, unclear documentation, or missing features
- **Propose schema changes** — open an issue or pull request; include the rationale and a before/after example
- **Add examples** — new domain examples are welcome; they must validate against the schema
- **Improve documentation** — corrections, clarifications, and new guides
